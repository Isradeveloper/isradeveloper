# 💫 About Me
## 💻 Senior Software Engineer | Full-Stack & Software Architecture

Systems Engineer and Senior Software Engineer with a full-stack focus, specializing in software design, scalable systems architecture, and cloud-native solutions. Experienced in leading technical decisions and designing decoupled, resilient, and growth-ready architectures using **Domain-Driven Design (DDD)**, **Hexagonal Architecture**, **CQRS**, and **SOLID principles**.

My backend core centers on **TypeScript (NestJS, Express, Node.js)** and **Python (FastAPI, Django, Flask)**, paired with **PostgreSQL, MongoDB, and Redis**. I design high-throughput REST and GraphQL APIs, as well as asynchronous event-driven pipelines using **BullMQ and RabbitMQ**.

On the frontend, I build modern, maintainable user interfaces using **React, Next.js, and Vue.js** with TypeScript and Tailwind CSS, balancing high engineering standards with seamless user experience.

Beyond core development, I architect and deploy cloud infrastructure on **AWS** (ECS, S3, SNS, Cognito) and **Azure**, leveraging Docker, Kubernetes, and automated CI/CD pipelines. I also leverage AI-assisted engineering tools (**Cursor, GitHub Copilot, Claude Code**) to streamline refactoring and accelerate delivery.
